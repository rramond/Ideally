### **2. Project window**

The project window simulates the entire app on a smaller scale. Its purpose is to work on isolated projects, creating timelines, making notes, adding files and structuring the workflow.

c) ✅ DONE — PROJECT FULL SCREEN
the app on a smaller scale, for one project. Clicking a droplet grows the page out of it (a circle opening from the droplet). On top: the project's droplet (click → color wheel, saved live) and its name (click to rename; Enter / clicking away saves, Esc reverts), "1 NOTE · 4 MILESTONES · 2 FILES" on the right. Below, a mini side rail (Notes · Timeline · Files, with counts; the last one opened is remembered per project) and "delete project" at its bottom (deletes its notes, timeline and stored files) — the rail later moved into the app's side panel and the project opens on the Board, see f) and g). Notes = the Notes tab in miniature (list + editor, saves as you type). Esc leaves a text field first, then goes back to the droplets; the droplet wobbles when you return. The droplets grow with notes + milestones + files

d) ✅ DONE — TIMELINE
milestones (one day) and spans (several days) on a horizontal axis in the project color, with a glowing TODAY line, month labels, day numbers (week ticks when zoomed out) and shaded weekends. Items sit in lanes above / below the axis so labels never overlap. Drag an item to move it (snaps to days, a tag shows the new date); drag a span's right edge to change its end; click opens it, right-click → Edit / Mark as done / Delete; double-click or right-click empty space → new milestone on that day. Wheel scrolls through time, Shift+wheel up / down, Ctrl+wheel (or − / +) zooms days → weeks → months around the cursor; Today scrolls back. Header: progress bar "1 / 4 done". Below: the same items as a checklist in date order (checkbox toggles done; "in 3 days", "ongoing · 5 days left", "2 days late" in red, done struck through). Milestone overlay: name, Date (or Starts → Ends with "Lasts several days", moving the start keeps the length), Done, description, Ctrl+Enter saves — later reworked into the Roadmap, see 2h (the checklist and the milestone overlay were replaced by the List view and the item side panel)

e) ✅ DONE — FILE ATTACHMENTS
drop files anywhere on the project page (a dashed "Drop to attach to …" frame appears), paste them (Ctrl+V), or "+ Add files". Stored in IndexedDB (src/projects/fileStore.js), not localStorage, so big files fit (200 MB max each); the project keeps only name / size / type / date. A grid of cards: image thumbnails, other files a colored extension badge (PDF red, CSV green…). Click opens: images in a preview pop-up (with Download), PDFs / text / audio / video in a new tab, the rest downloads; right-click → Open / Download / Rename (inline, the extension isn't selected) / Delete

- stickies: + Sticky (lands in the nearest free spot) or double-click empty space (lands there); double-click / Enter to type; the color swatch (color wheel) sets the color of new stickies and recolors the selected one, remembered (ideally.projectStickyColor); dark colors get light text
- files: drop them anywhere on the project page (they land where dropped on the board), paste (Ctrl+V), + File, or Place file (one already stored in Files). Every file put on the board is also stored in Files. Images show as the picture (keeping their shape when resized, name on hover), other files as a card with the colored extension badge; double-click opens like in Files

- drag to move (the clicked item comes to the front), corner grip resizes, drag empty space to pan, wheel zooms around the cursor, the % pill resets; Delete / Backspace removes the selected item; right-click: sticky → Edit text / Use the current color / Duplicate / Delete, file → Open / Download / Remove from board / Delete file, empty → New sticky here / Add files here / Place a file from Files here

h) ✅ DONE — ROADMAP (Jira Product Discovery style): the project's Timeline section became the Roadmap (side panel entry renamed), with one set of items shown three ways — tabs Columns · List · Timeline (the last one used is remembered)
- items: name, description, Roadmap column (Now / Next / Later, set by hand), status (fixed: On track green, At risk yellow, Off track red, Pending grey, Done blue), goal (the project's own goal tags, name + color), date (an exact day or a span, a month "Nov 2026", or a quarter "Apr–Jun 2027"), steps (a checklist → the progress bar) and documents (this project's files and web links)
- the existing timeline items were upgraded once: done → Done, the rest Pending; started / overdue → Now, starting within ~2 months → Next, the rest → Later
- toolbar: the view tabs, overall progress "1 / 4 done", search (name + description), Filter (status / roadmap / goal checkboxes, shared by the three views, kept while the app is open), + Item (makes one in Now, opens it with the name ready to type)
- Columns: Now / Next / Later with counts; cards show the name, the start of the description, goal, status and date chips, and progress / number of documents; drag a card to another column or place (the order is kept, a dashed placeholder shows where); "+ Create" under a column adds one there (Enter, stays open for the next)
- List: a table — Summary · Roadmap · Status · Goal · Date · Progress · Documents; click a column title to sort (again: reverse); group by Roadmap / Status / Goal; the Roadmap and Status chips change with a click; "+ Create" row at the bottom
- Timeline: the 2d axis; items colored by status (done dimmed), the goal's dot and a thin progress line on the label; months / quarters drawn as dashed soft bands and dragged by month / quarter; zooms out further (to quarters); the checklist under it is gone (the List replaces it)
- item side panel: clicking any card / row / label slides it in at the right (the view stays beside it, like Jira): editable name, Roadmap / Status buttons, goal picker (pick, + New goal with a color wheel, ✎ edit / delete — a deleted goal leaves its items without one), date (Day / Month / Quarter, with "several days" for a span), description (saves as you type), steps (add with Enter, tick, double-click to edit, × to remove), documents (+ Project file from a menu, + Web link with an optional label; click opens, × unlinks — deleting a file in Files unlinks it everywhere), delete item. Every change saves at once; Esc / × / the logo close it
